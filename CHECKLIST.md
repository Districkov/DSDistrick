## Решение проблем

### Бот не подключается к Discord

**Проверить:**
- [ ] Токен правильно скопирован (без пробелов)
- [ ] Переменная окружения установлена на Render
- [ ] Message Content Intent включен

**Решение:**
```bash
# Локально
# Убедитесь, что config.json содержит правильный токен

# На Render
# Проверьте: Dashboard → Service → Environment → DISCORD_BOT_TOKEN
```

### Ошибка: "config.json not found"

**Это нормально!** Код специально разработан для чтения переменных окружения.

**Проверить:**
- [ ] На Render установлена переменная `DISCORD_BOT_TOKEN`
- [ ] На локальной машине используется `config.json`

### Модали не срабатывают

**Проверить в консоли:**
```
🔔 ModalInteraction car_request_modal получен
```

Если этой строки нет:
- [ ] Убедитесь, что Message Content Intent включен
- [ ] Проверьте ID канала в config.json
- [ ] Перезагрузите Discord (закройте и откройте)

**Решение:**
1. Discord Developer Portal → Bot
2. Включите **Message Content Intent**
3. Подождите 1-2 минуты
4. Попробуйте снова

### Обработчик компонентов не срабатывает

**Проверить структуру:**
```csharp
[ComponentInteraction("custom_id_*")] // pattern должен совпадать
[ModalInteraction("modal_id*", ignoreGroupNames: true)]
```

**Решение:**
- Убедитесь, что `CustomId` в кнопке совпадает с паттерном в атрибуте
- Используйте `ignoreGroupNames: true` для модалей
- Проверьте консоль на строку "🔔 Interaction получен"
