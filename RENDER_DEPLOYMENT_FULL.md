# Развертывание на Render — пошаговая инструкция

## Что такое Render?

Render — это современная облачная платформа для развертывания приложений. Она простая в использовании, поддерживает Docker и имеет бесплатный уровень.

## Минимальные требования

✅ GitHub репозиторий с вашим кодом  
✅ Discord токен бота  
✅ Учетная запись на [Render.com](https://render.com)

## Шаг 1: Подготовка репозитория

Убедитесь, что все файлы закоммичены и залиты на GitHub:

```bash
git status
git add .
git commit -m "Prepare for Render deployment"
git push origin main
```

**Важно:** В репозитории должны быть:
- ✅ `Dockerfile` (есть)
- ✅ `render.yaml` (создан)
- ✅ `Program.cs` и все исходные коды
- ❌ `config.json` (должна быть в `.gitignore`!)

## Шаг 2: Подготовить Discord токен

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications)
2. Выберите ваше приложение
3. На вкладке **"Bot"** скопируйте **TOKEN**
4. **БЕЗОПАСНОСТЬ:** Не коммитьте токен в репозиторий!

## Шаг 3: Создать сервис на Render

1. Откройте [Render Dashboard](https://dashboard.render.com)
2. Нажмите **"New +"** → **"Web Service"**
3. Нажмите **"Build and deploy from a Git repository"**
4. Подключите GitHub (если не подключен)
5. Выберите репозиторий **DSDistrick**

## Шаг 4: Конфигурация сервиса

Заполните параметры:

| Параметр | Значение | Описание |
|----------|----------|---------|
| **Name** | `discord-bot` | Имя сервиса (может быть любым) |
| **Environment** | `Docker` | Тип развертывания |
| **Region** | `Frankfurt` (или ближайший) | Географический регион |
| **Branch** | `main` | Ветка для развертывания |
| **Build Command** | (оставить пусто) | Используется Dockerfile |
| **Start Command** | (оставить пусто) | Используется Dockerfile |

## Шаг 5: Добавить переменные окружения

В разделе **"Environment"** добавьте:

```
Key: DISCORD_BOT_TOKEN
Value: ВАШ_ТОКЕН_БОТА
```

**Как это работает:**
- Код читает `DISCORD_BOT_TOKEN` из переменных окружения
- На локальной машине используется `config.json`
- На облаке используются переменные Render

## Шаг 6: Запуск развертывания

1. Нажмите кнопку **"Create Web Service"**
2. Ждите завершения развертывания (~5-10 минут)

**Статусы развертывания:**
- 🔵 `Building...` — собирается Docker образ
- 🔵 `Deploying...` — развертывается сервис
- 🟢 `Live` — успешно запущен!
- 🔴 `Failed` — ошибка (смотрите логи)

## Шаг 7: Проверить логи

Если развертывание завершилось с ошибкой:

1. Откройте ваш сервис в Render
2. Перейдите на вкладку **"Logs"**
3. Ищите ошибку в логах

**Типичные ошибки:**

```
❌ КРИТИЧЕСКАЯ ОШИБКА: BotToken не установлен
```
→ Проверьте, что переменная окружения установлена в Render

```
Unhandled exception: No such file or directory 'config.json'
```
→ Хорошо! Это нормально — код правильно читает переменные окружения

## Как получить URL бота

После успешного развертывания:

1. Перейдите на вкладку **"Settings"** вашего сервиса
2. Скопируйте URL (например: `discord-bot-xyz.onrender.com`)
3. Этот URL доступен в интернете

## Что делать, если бот упал

Render автоматически перезапускает упавшие приложения.

Если нужно перезапустить вручную:
1. Откройте ваш сервис
2. Нажмите **"Restart"** на вкладке **"Dashboard"**

## Отладка на Render

Render показывает логи в реальном времени на вкладке **"Logs"**.

Вы увидите:
```
🔐 Попытка подключения к Discord...
   ✅ Токен загружен из переменной окружения DISCORD_BOT_TOKEN

✅ Бот BotName#1234 готов!
   Статус: Connected
```

## Обновление бота на Render

1. Внесите изменения в код локально
2. Закоммитьте и запушьте в GitHub:
   ```bash
   git commit -am "Fix: modal components"
   git push origin main
   ```
3. Render автоматически заметит изменения и пересоберет бота (~3-5 минут)

**Отключить автоматическое развертывание:**
- На вкладке **"Settings"** найдите **"Auto-Deploy"**
- Выберите **"Disabled"**

## Стоимость

- 🟢 **Бесплатно:** 750 часов в месяц (один сервис 24/7)
- 💳 **Платно:** $7/месяц за гарантированный аптайм

## Дополнительно

### Как остановить бота?
1. Откройте ваш сервис
2. Нажмите **"Suspend"** (или **"Delete"** для удаления)

### Как изменить токен?
1. Откройте сервис
2. На вкладке **"Environment"** отредактируйте переменную
3. Нажмите **"Save Changes"** 
4. Render автоматически перезапустит бота
