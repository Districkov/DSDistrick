# 🎮 Discord Bot для GTA 5 Семьи

Полнофункциональный Discord бот на C# с использованием Discord.Net для управления семьей в GTA 5, запросами транспорта, выбором машин, логированием событий и интеграцией с социальными сетями.

## 🎯 Основные возможности

### 1️⃣ 👨‍👩‍👧‍👦 Система заявок в семью
- **Модальное окно** при команде `/family apply` с полями:
  - Ник в игре
  - Полное имя
  - Статус онлайна (время активности)
  - О себе (опыт в игре)
  - Причина присоединения к семье
- Автоматическое отправление заявки в канал администраторов
- Одобрение/отклонение заявок с уведомлением пользователя
- Все события логируются в канал логов

### 2️⃣ 🚗 Выбор машин и запрос транспорта (объединено)
- **Единая система**: пользователь указывает пункт назначения и причину поездки
- Dropdown меню с отображением:
  - ✅ Свободных машин
  - ❌ Занятых машин (с указанием владельца)
- Автоматическое обновление статуса машин после выбора
- Все запросы логируются с информацией о пункте назначения и причине
- История выбора машин в реальном времени

### 3️⃣ 📋 Система логирования
- **Автоматическое логирование** всех событий:
  - Заявки в семью
  - Одобрение/отклонение заявок
  - Выбор машин с указанием пункта назначения
  - Поездки пользователей
  - Присоединение пользователей
- Все логи отправляются в отдельный канал Discord
- Просмотр логов администраторами через `/admin logs`

### 4️⃣ 📱 Интеграция с социальными сетями
- Поддержка **Twitch**, **YouTube**, **TikTok**
- Управление каналами через `/socials`
- Отправка уведомлений о новых стримах/видео

## 📋 Требования

- **.NET 6.0** или выше
- **Discord бот токен** ([Создать в Discord Developer Portal](https://discord.com/developers))
- **5 каналов Discord**:
  - 📝 Канал заявок в семью
  - 🚗 Канал запросов транспорта
  - ✅ Канал одобрения заявок
  - 📋 Канал логов сервера
  - 📱 Канал уведомлений социальных сетей

## ⚡ Быстрый старт

### Шаг 1: Запустить бота

**Вариант 1: Батник (Windows)**
```bash
run.bat
```

**Вариант 2: PowerShell (Windows)**
```powershell
.\run.ps1
```

**Вариант 3: Bash (Linux/Mac)**
```bash
bash run.sh
```

### Шаг 2: Отправить меню в каналы

После запуска бота используйте команды для отправки меню в нужные каналы:

```
/setup family-menu          # В канал заявок в семью
/setup auto-menu            # В канал выбора машин и запросов
```

### Шаг 3: Готово!

Теперь пользователи видят меню с кнопками и могут:
- Нажать кнопку → Заполнить форму (куда, зачем) → Выбрать машину → Готово
- Администраторы видят логи всех поездок в канале логов
- Все события логируются автоматически

## 📝 Команды

### ⚙️ Команды для администраторов

#### Отправка меню
- `/setup family-menu` - Отправить меню заявок в семью (с кнопкой подачи заявки)
- `/setup auto-menu` - Отправить единое меню выбора машин и запросов (с кнопкой открытия)

#### Просмотр активных заявок
- `/admin list` - Список активных заявок в семью
- `/admin view` - Просмотреть список машин
- `/admin status` - Статус всех машин
- `/admin list` (транспорт) - Список активных запросов

#### Управление системой
- `/admin logs [count]` - Просмотреть логи (только админам)
- `/admin socials` - Настроить социальные сети (только админам)

## 🛠️ Процессы

### 📋 Процесс заявки в семью
1. Пользователь вводит `/family apply`
2. Открывается модальное окно с 5 полями
3. Пользователь заполняет данные и отправляет
4. Заявка отправляется в канал администраторов
5. Администратор одобряет/отклоняет
6. Пользователь получает уведомление
7. Событие логируется в канал логов

### 🚗 Процесс выбора машины и запроса (объединено)
1. Пользователь нажимает кнопку "Выбрать машину" в меню
2. Открывается модальное окно с полями: пункт назначения и причина
3. Пользователь заполняет данные и отправляет
4. Открывается dropdown меню со списком машин (✅/❌ со статусом)
5. Пользователь выбирает машину из списка
6. Машина помечается как занятая
7. Уведомление с информацией о поездке отправляется в канал логов
8. Пользователь получает подтверждение с деталями поездки
7. Событие логируется

## 🛠️ Как это работает

### Процесс заявки в семью
1. Пользователь использует `/family apply`
2. Заполняет модальное окно с информацией о себе
3. Заявка отправляется в канал заявок и канал одобрения
4. Администратор нажимает кнопку одобрения/отклонения
5. Пользователь получает уведомление в личные сообщения
6. Событие логируется в систему

### Процесс запроса транспорта
1. Пользователь использует `/transport request`
2. Заполняет модальное окно с пункт назначения и причиной
3. Запрос отправляется в канал запросов
4. Администратор нажимает кнопку "Выбрать транспорт"
5. Выбирает тип машины из dropdown меню
6. Машина отправляется в канал одобрения с деталями

### Процесс выбора машины
1. Пользователь использует `/auto select`
2. Выбирает машину из dropdown меню
3. Выбор автоматически публикуется в канале выбора авто

### Логирование
- Все события (заявки, запросы, одобрения, выборы) логируются
- История хранится в памяти (до 1000 записей)
- Администраторы могут просматривать логи через `/admin logs`

### Социальные сети
- Администраторы добавляют каналы социальных сетей через `/socials add`
- Система может отправлять уведомления о новых видео/стримах
- Поддерживается интеграция с Twitch, YouTube, TikTok
