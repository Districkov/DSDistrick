## Как использовать

### Локально (Windows/Mac/Linux)

1. **Установите токен в `config.json`:**
   ```json
   {
     "BotToken": "ВАШ_ТОКЕН_ЗДЕСЬ",
     "ApplicationId": "ВАШ_ID_ЗДЕСЬ"
   }
   ```

2. **Запустите:**
   ```bash
   dotnet run --project .
   ```

3. **Смотрите логи в консоли**

### На Render.com

1. Залейте код на GitHub
2. Создайте Web Service на Render
3. Добавьте переменную окружения:
   - `DISCORD_BOT_TOKEN` = ваш токен
4. Нажмите "Deploy"

## Примеры ошибок и решения

### ❌ BotToken не установлен
```
Решение: Добавьте значение в config.json или установите DISCORD_BOT_TOKEN
```

### ❌ Modal не срабатывает
```
Проверьте консоль:
  🔔 ModalInteraction modal_id получен = ДА ✅
  🔔 ModalInteraction modal_id получен = НЕТ ❌
  
Если нет — включите Message Content Intent в Developer Portal
```

### ❌ Компоненты (кнопки/меню) не работают
```
Возможные причины:
1. Message Content Intent не включен
2. CustomId не совпадает с паттерном в атрибуте
3. Бот не имеет прав на отправку сообщений
```
